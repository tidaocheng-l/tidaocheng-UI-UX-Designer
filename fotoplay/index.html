FotoPlay
从一键成片
到专业时间轴

FotoPlay 是一款面向全球市场的移动视频剪辑 App（Android / iOS 双端）。项目围绕 「降低上手门槛」与「保留专业深度」两条主线展开：上手侧用 Try 一键成片、视频模板与卡点主题承接创作动机； 专业侧以主轨道时间轴 + 特效 / 文字 / 字幕 / 画中画 / 关键帧曲线构成完整的编辑链路。 本作品集按功能板块整理，每个板块均取当前最新设计稿。

设计策略

DESIGN STRATEGY
⌗
双端并行交付

Android / iOS 组件成对设计维护，控件、导航、弹窗均有双端规范，保证体验一致的同时尊重平台习惯。

◐
深色优先体系

深色模式不是简单反色：以 #131415 为基准建立 11 级明度阶，配合白色透明度层级控制信息层级。

文A
多语言本地化

产品页覆盖英 / 德 / 西 / 葡四语种，界面布局预留文本膨胀空间，商店素材按语言重排版。

◆
组件库驱动

系统组件 / 导航 / 功能组件 / List 双端组件库支撑 200+ 页面一致性，新功能优先组合现有组件。
